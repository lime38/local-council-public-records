# 조사 방법론

## 목적과 조사 대상

시민·기자·연구자·개발자가 공식 기록으로 이동할 수 있도록 기관별 접근 경로를 정리합니다.
v0.1.0은 거제·성남·고양·강남·송파의 5개 지방의회만 다루는 베타입니다.
이 5지역은 첫 공개 범위이며 전국을 대표하는 통계 표본으로 추출한 것이 아닙니다.
대상 경로는 각 기관의 홈페이지, 회의록 진입점, 의안 진입점으로 최대 15개입니다.

## 확인 방법

1. 기관 공식 홈페이지 또는 공식 메뉴를 근거로 기관과 URL의 관계를 확인합니다.
2. 페이지의 제목·메뉴·목록 등에서 해당 경로의 용도를 확인합니다.
3. 확인한 URL, 근거 URL, 관찰·확인 시각, 실제 사용한 방법과 기간 제한을 함께 기록합니다.
4. 확인하지 못한 값은 `null`로 남깁니다. 실패·오류를 자료 부재로 바꾸지 않습니다.
5. 같은 JSON 입력에서 CSV와 웹 목록을 만들고, 공개 키와 값이 일치하는지 검사합니다.

`navigation_observed`는 공식 페이지의 메뉴·제목·목록을 관찰했다는 뜻입니다.
웹 도구가 캐시된 내용을 반환할 수 있으므로 이 상태만으로 원서버의 최신 응답을 인증하지 않습니다.
`http_response_checked`는 표시된 시각에 HTTP 응답을 직접 확인했다는 뜻입니다.
HTTP 응답 확인 자체는 검색 기능·첨부 열기·모든 기간 자료의 이용 가능성을 인증하지 않습니다.
`unknown`은 해당 확인 상태를 확정하지 못했다는 뜻입니다.
확인 상태는 자료의 공개 여부나 기관의 투명성 점수가 아닙니다.

## 데이터와 재현

정본 다운로드는 [JSON](../data/councils.json)이며 [CSV](../data/councils.csv)는 같은 필드를 같은 순서로 제공합니다.
JSON `null`은 CSV의 빈 칸에 대응합니다. 기관 식별자는 이 리소스가 사용하는 문자열이며 행정기관의 공식 코드가 아닙니다.
필드별 의미는 [필드 설명](fields.md), 기계 검증 형식은 [스키마](../schema/councils.schema.json)를 참고해 주세요.
[릴리스 정보](../release.json)는 버전·기준일·대상 수·대표 URL과 파일별 SHA-256을 연결합니다.
`manifest.sha256`의 각 해시는 해당 상대 경로 파일의 원래 바이트에 적용됩니다.
해시 일치는 파일 동일성을 확인하며 출처 내용의 정확성을 대신하지 않습니다.

## 한계와 재사용

홈페이지·메뉴·최근 목록은 과거 기록 전체의 범위를 보장하지 않습니다. 경로별 `scope`를 먼저 확인해 주세요.
특히 의회 대수별 검색 경로가 나뉜 경우 한 경로를 모든 기간의 자료라고 해석하지 않습니다.
검색 실행·페이지 이동·첨부 다운로드·모바일 이용·접근성의 완전한 기능 조사는 포함하지 않습니다.
로그인·접근 제한을 우회하지 않으며, 원문·첨부·로고를 내려받아 재배포하지 않습니다.
이 자료를 바탕으로 만든 앱·기사·연구는 이용한 버전과 개별 원출처를 함께 밝혀 주세요.

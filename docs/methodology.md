# 조사 방법론

## 목적과 조사 대상

시민·기자·연구자·개발자가 공식 기록으로 이동할 수 있도록 기관별 접근 경로를 정리합니다.
v0.2.2는 기존 거제·성남·고양·강남·송파를 포함한 20개 지방의회 안내 경로를 다루는 베타입니다.
이 20개 의회는 이번 공개 범위이며 전국을 대표하는 통계 표본으로 추출한 것이 아닙니다.
대상 항목은 각 기관의 홈페이지, 회의록, 의안, 의원 안내로 80개 칸입니다. 알 수 없는 URL은 null이며 확인된 링크 수와 기관 수를 구분합니다.

## 확인 방법

1. 기관 공식 홈페이지 또는 공식 메뉴를 근거로 기관과 URL의 관계를 확인합니다.
2. 페이지의 제목·메뉴·목록 등에서 해당 경로의 용도를 확인합니다.
3. 확인한 URL, 근거 URL, 관찰·확인 시각, 실제 사용한 방법과 기간 제한을 함께 기록합니다.
4. 확인하지 못한 값은 `null`로 남깁니다. 실패·오류를 자료 부재로 바꾸지 않습니다.
5. 같은 JSON 입력에서 CSV와 웹 목록을 만들고, 공개 키와 값이 일치하는지 검사합니다.

`navigation_observed`는 공식 페이지의 메뉴·제목·목록을 관찰했다는 뜻입니다.
웹 도구가 캐시된 내용을 반환할 수 있으므로 이 상태만으로 원서버의 최신 응답을 인증하지 않습니다.
`http_response_checked`는 표시된 시각에 HTTP 응답을 직접 확인했다는 뜻입니다.
HTTP 응답 확인 자체는 검색 기능·첨부 열기·모든 기간 자료의 이용 가능성을 인증하지 않습니다.
`unknown`은 해당 확인 상태를 확정하지 못했다는 뜻입니다.
확인 상태는 자료의 공개 여부나 기관의 투명성 점수가 아닙니다.

## 데이터와 재현

정본 다운로드는 [JSON](../data/councils.json)이며 [CSV](../data/councils.csv)는 같은 필드를 같은 순서로 제공합니다.
JSON `null`은 CSV의 빈 칸에 대응합니다. 기관 식별자는 이 리소스가 사용하는 문자열이며 행정기관의 공식 코드가 아닙니다.
필드별 의미는 [필드 설명](fields.md), 기계 검증 형식은 [스키마](../schema/councils.schema.json)를 참고해 주세요.
[릴리스 정보](../release.json)는 버전·기준일·대상 수·대표 URL과 파일별 SHA-256을 연결합니다.
`manifest.sha256`의 각 해시는 해당 상대 경로 파일의 원래 바이트에 적용됩니다.
해시 일치는 파일 동일성을 확인하며 출처 내용의 정확성을 대신하지 않습니다.

## 한계와 재사용

홈페이지·메뉴·최근 목록은 과거 기록 전체의 범위를 보장하지 않습니다. 경로별 `scope`를 먼저 확인해 주세요.
특히 의회 대수별 검색 경로가 나뉜 경우 한 경로를 모든 기간의 자료라고 해석하지 않습니다.
검색 실행·페이지 이동·첨부 다운로드·모바일 이용·접근성의 완전한 기능 조사는 포함하지 않습니다.
로그인·접근 제한을 우회하지 않으며, 원문·첨부·로고를 내려받아 재배포하지 않습니다.
이 자료를 바탕으로 만든 앱·기사·연구는 이용한 버전과 개별 원출처를 함께 밝혀 주세요.

파일과 정정: [공개 GitHub 저장소](https://github.com/lime38/local-council-public-records)

## v0.2.0 확인 범위

기관 구분(광역·기초)과 공식 의원 안내 링크를 추가했습니다. 의원 개인의 이름·연락처·사진은 수집·재배포하지 않습니다.
직접 접속한 페이지, 공식 메뉴의 연결 URL, 다른 공식 의회 사이트의 관련기관 목록에서 관찰한 홈페이지 주소를 구분합니다. 관찰 경로는 각 필드의 source_url/method/scope에 기록했습니다.
주소를 확보하지 못한 항목의 URL은 null입니다. 제공받은 URL은 확인 대기 상태로도 공개할 수 있으며, 이때 확인 시각을 만들지 않습니다. HTTP 200만으로 기능·전체 기간·현역 명부의 완전성이나 최신성을 인증하지 않습니다. API 원문·기관 데이터베이스를 복제한 자료가 아닙니다.

## v0.2.1 링크 보완

충북 회의록·의안·의원 안내 URL은 사용자 제보에서 받았습니다. 회의록은 공식 페이지의 캐시된 제목·메뉴를 대조했으며, 의안·의원 안내는 자동 조회 제한·도구 시간 초과로 화면 확인 대기입니다. 두 URL은 보존하고 `status=unknown`, `checked_at=null`로 구분합니다. 자동 수집 제한이나 도구 오류를 링크 부재로 처리하지 않습니다. 공통 URL 형식은 탐색 후보를 만드는 데만 쓰며, 다른 의회 주소를 자동 확정하지 않습니다.

## v0.2.2 공식 경로 보완

20개 의회의 80개 URL을 제공하며, 공식 메뉴·페이지 관찰 또는 HTTP 응답 확인 78개와 사용자 제공·화면 미확인 2개를 구분합니다. 공통 URL 구조로 후보를 찾은 뒤 실제 공식 메뉴의 href 또는 공식 페이지 관찰로 대조했습니다. 유사한 구조라는 이유만으로 경로를 확정하지 않았습니다.

대전 의안은 계류의안, 제주 의안은 제11대 안내, 제주 의원은 교육의원·비례대표 안내라는 한계가 있습니다. 이런 일부 범위의 경로를 전체·현직 명부 또는 모든 대수의 검색으로 표시하지 않습니다. 목적지 자동 조회 실패와 캐시 메뉴에서 링크를 발견한 사실도 구분합니다.

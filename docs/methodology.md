# 조사 방법론

## 대상

v0.2.4은 24개 지역의 홈페이지·회의록·의안·의원 안내 링크 96개를 제공합니다.
기관 이름과 지역, 광역·기초 구분, 공식 URL 및 확인 기록을 함께 정리합니다.
지역 수는 잘하나의 공개 지역 구분입니다. 전남·광주는 통합 전 의회 자료와 현행 통합의회 링크를 구분하며, 현행 링크가 같은 경우도 있습니다.

## 링크 확인과 갱신

공식 홈페이지의 메뉴와 페이지를 대조하고, 이용자가 직접 방문해 확인한 주소를 반영합니다.
회의록은 최근회의록 목록으로 바로 연결합니다. 같은 솔루션은 공통 URL 구조를 활용하고 공식 메뉴의 연결 주소를 대조합니다. 의안도 검색·목록 진입 주소를 우선합니다.
각 링크의 용도는 `scope`, 출처는 `source_url`, 확인 경위는 `method`에 기록합니다.

- `navigation_observed`: 공식 메뉴·페이지에서 주소를 관찰했습니다.
- `http_response_checked`: 직접 HTTP 응답을 확인했습니다.
- `user_confirmed`: 사용자가 직접 접속한 결과를 전달했습니다.

`checked_at`은 관찰·확인을 기록한 시각입니다. 사용자 확인은 보고를 받은 시각으로 기록합니다.
이전 주소와 조사 기록은 버전별 변경 이력에 보존합니다.

## 파일과 재현

[JSON](../data/councils.json)과 [CSV](../data/councils.csv)는 동일한 24행·31필드입니다.
JSON의 `null`은 CSV의 빈 칸에 대응합니다. UTF-8로 제공합니다.
[필드 설명](fields.md)과 [스키마](../schema/councils.schema.json)에서 형식을 확인할 수 있습니다.
[릴리스 정보](../release.json)와 [SHA-256 목록](../manifest.sha256)은 버전과 파일을 연결합니다.
웹 목록과 다운로드, 공개 GitHub는 같은 입력에서 생성합니다.

## 출처와 인용

기관 원문은 공식 링크에서 이용하며, 이 자료는 접근 경로와 자체 작성 메타데이터를 제공합니다.
이용 시 자료명·잘하나·버전·기준일·대표 URL을 함께 인용해 주세요.
